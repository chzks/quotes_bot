# Quotes Bot

Telegram-бот, который присылает случайные цитаты, собранные с сайта [quotes.toscrape.com](https://quotes.toscrape.com/) в реальном времени — с поддержкой перевода и фильтрации по темам.

## Возможности

- Команда `/quotes` — присылает случайную цитату с автором и тегами
- Кнопка **«Another quote»** — получить ещё одну цитату без повторного ввода команды
- Команда `/language` — выбор языка цитаты (🇷🇺 Русский / 🇬🇧 English), перевод выполняется автоматически
- Команда `/topics` — выбор темы цитат (love, life, inspirational, humor, success или все темы сразу)
- Данные собираются напрямую с сайта через веб-скрейпинг и кэшируются для скорости
- Устойчивость к сбоям переводчика — при ошибке перевода бот покажет оригинальный текст вместо падения

## Стек

- Python 3.14
- [aiogram 3.x](https://docs.aiogram.dev/) — асинхронный фреймворк для Telegram-ботов
- `requests` + `BeautifulSoup4` — сбор данных с сайта
- `deep-translator` — перевод текста цитат
- `python-dotenv` — безопасное хранение токена бота

## Архитектура

```
quotes_bot/
├── main.py            # логика бота: команды, клавиатуры, кэш, перевод, запуск polling
├── parser.py          # веб-скрейпинг: получение и парсинг цитат с сайта
├── requirements.txt    # зависимости проекта
└── .env                # токен бота (не публикуется, см. .gitignore)
```

Логика бота и логика парсинга разделены на разные модули — `main.py` ничего не знает об устройстве HTML-страницы, а `parser.py` ничего не знает про Telegram.

Цитаты кэшируются в памяти при старте (для темы «все») и лениво при первом обращении к конкретной теме — это снижает нагрузку на сайт и ускоряет ответы бота. Язык и тема хранятся отдельно для каждого пользователя (по `user_id`), поэтому предпочтения не пересекаются между разными людьми, использующими бота одновременно.

## Установка и запуск

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/твой_username/quotes_bot.git
   cd quotes_bot
   ```

2. Создать и активировать виртуальное окружение:
   ```bash
   python -m venv venv
   venv\Scripts\Activate.ps1      # Windows
   source venv/bin/activate         # Linux/Mac
   ```

3. Установить зависимости:
   ```bash
   pip install -r requirements.txt
   ```

4. Создать файл `.env` в корне проекта и указать токен бота, полученный от [@BotFather](https://t.me/BotFather):
   ```
   TOKEN=твой_токен_бота
   ```

5. Запустить бота:
   ```bash
   python main.py
   ```

## Пример использования

1. Отправить боту `/start`
2. `/language` → выбрать русский — все дальнейшие цитаты будут переводиться
3. `/topics` → выбрать тему, например «Love»
4. `/quotes` — придёт случайная переведённая цитата на выбранную тему
5. «Another quote» — новая цитата в том же языке и теме

## Возможные улучшения

- Хранение предпочтений пользователя (язык, тема) в файле/базе данных, чтобы они не сбрасывались при перезапуске бота
- Официальный API перевода (например, DeepL) вместо неофициального доступа для большей стабильности
- Периодическое обновление кэша цитат в фоне
- Добавление большего числа тем и языков перевода
